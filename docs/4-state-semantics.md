# 四值语义口径(权威定义)

> 目的:把 x/z 在所有入口上的行为**一次写清**,避免"同一波形不同算子给出不同答案"。
> 口径对齐 IEEE 1364/1800 的四值约定 + 本项目的"逐索引"模型。
> 所有实现都必须与本文一致;不一致即为 bug(`tests/golden_tiny.rs` 是本文的可执行版本)。

## 0. 索引模型

- 索引 = VCD `#` 时间戳的出现顺序(0,1,2,…),FST 用其时间表。
- **某索引处的值 = 该时间戳内最后一次写入**(delta 周期/毛刺:最后写入胜出)。
- 索引 0 的初值:VCD 取 `$dumpvars` 快照(没有则 `x`);FST 无快照概念,视作 `x`。
- 值域:0 / 1 / x / z(大小写归一为小写);多位值为位串(MSB 在前)。

## 1. 取值与显示(`get` / `at` / `getwave`)

| 情况 | 结果 |
|---|---|
| 全 0/1 的多位值 | 整数(如 `b00000101` → `5`) |
| 含 x 或 z | **位串**(如 `"00x1"`、`"x"`、`"z"`) |
| 1 位 x/z | `"x"` / `"z"`(不是 0!) |
| real | 浮点数 |
| `(at s T)` | `(时间 值)`;T 之前无变化 → `(0 初值)` |

**游标语义**:`(get s)` 取**当前 INDEX** 处的值,不随 `map`/遍历位置变化;
按时间取值请用 `(at s T)` 或 `(sample-at s indices)`。

## 2. 比较(`=` / `==` / `!=` / `>` …)

- 两侧都能规约为整数(**无 x/z**)→ 按整数比较。
- 任一侧含 x/z → **按位串比较**:逐位相同才相等;`x` 与 `0`、`z` 与 `0` 都**不相等**。

| 表达式 | 结果 | 说明 |
|---|---|---|
| `(= (get a) 0)`(a 为 x) | `false` | x 不等于 0 |
| `(!= (get a) 0)`(a 为 x) | `true` | 同上,取反 |
| `(= (get b) 5)`(b = `00x1`) | `false` | 含 x → 位串比较 |
| `(= (get b) 5)`(b = `0101`) | `true` | 纯 0/1 → 整数 5 |

## 3. 真值(条件位置,如 `if`/`&&`/`count` 的条件)

- 整数 `0` → 假;非 0 → 真。
- 含 x/z 的**位串** → **假**(未知不算真)。
- `nil` → 假;字符串非空 → 真。

## 4. 边沿与变化(`rising` / `falling` / `changes`)

| 谓词 | 定义 |
|---|---|
| `(rising s)` | 前一索引值为**全 0**,当前索引值为**确定的非零** |
| `(falling s)` | 前一索引值**确定的非零**,当前为**全 0** |
| `(changes s)` | 前后两索引的值**语义不同** |

- `x`/`z` 既不是 0 也不是"确定的非零" → **x→1、x→0 都不算边沿**;
  但 `x→1` **算一次变化**(值确实变了)。
- `x→x`、`z→z`、`x→z` **不算变化**(同属未知)。
- **索引 0 没有前驱**:除非 `$dumpvars` 给了**确定**初值,否则索引 0 处不可能有边沿。
  - `$dumpvars` 初值 0、`#0` 变 1 → **算一次上升沿**(初值就是前驱)。
  - 无 `$dumpvars`(初值 x)、`#0` 变 1 → **不算上升沿**(前驱未知),`changes` 也不算。
  - 工具会在"信号无确定初值 + 边沿查询"时打印一次性 warning 提示这一点。

## 5. 聚合入口的一致性

`count` / `count/step` / `count` 子命令(`wal-rust count <wave> <sig> <v>`)/ `find` /
`getwave` / `whenever` **必须**给出同一口径的答案:

| 入口 | 语义 |
|---|---|
| `(count (= (get s) V))` | 值等于 V 的**索引数**(x 不等于 V) |
| `wal-rust count w s V` | 同上 |
| `(count/step ...)` | 同上(逐索引等价形式) |
| `(count (changes s))` | 变化的**索引数**(不含初值快照) |
| `(count (rising s))` | 上升沿的**索引数** |

> 注意:`count` 子命令默认 `V=1`,是**值计数**而不是变化计数;
> 变化次数请用 `(count (changes "s"))`。

## 6. 数据质量

- 波形本身可能"缺初值"(转储未包含 `$dumpvars`,或被截断):此时首边可能少 1。
  工具在边沿查询上给 warning;`scripts/` 与矩阵测试都可复现该行为。
- 被截断的 VCD(缺 `$enddefinitions`)会打印截断告警。
- EVCD(`$dumpports`)、FSDB、gzip/bzip2 压缩波形:明确报错,不静默降级。
